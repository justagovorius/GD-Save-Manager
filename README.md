\# GD Save Manager (Desktop \& Web)



A safe and reliable local backup tool for \*\*Geometry Dash\*\* and \*\*GDPS\*\* saves. It allows you to easily back up your progress and restore it if something goes wrong.



\## 🚀 Features

\- \*\*Two Versions:\*\* Available as a classic Desktop App (Tkinter) and a modern Web App (runs in your browser).

\- \*\*Cross-Platform:\*\* Works on Windows, macOS, and Linux.

\- \*\*Selective Backup:\*\* Choose exactly which save files you want to copy.

\- \*\*Built-in Explorer:\*\* Open save folders directly from the app.

\- \*\*Themes:\*\* Light, Dark, System, and AMOLED (pure black) themes.

\- \*\*Localization:\*\* Supports English, Russian, and System language auto-detection.

\- \*\*Privacy:\*\* The web version runs entirely locally (`127.0.0.1`) and auto-shuts down when you close the browser tab.



\## 📦 Versions

1\. \*\*Desktop (`gd\_save\_manager.py`):\*\* A standalone window application. No browser needed.

2\. \*\*Web (`gd\_save\_manager\_web.py`):\*\* Launches a local server and opens a beautiful UI in your default browser.



\## 🛠️ How to Run (from source)

1\. Install Python (3.8+).

2\. Run the desired version:

&#x20;  - Desktop: `python gd\_save\_manager.py`

&#x20;  - Web: `python gd\_save\_manager\_web.py`

3\. \*No external libraries are required!\*



\## 💻 How to compile to .exe (Windows)

1\. Install PyInstaller: `pip install pyinstaller`

2\. Compile:

&#x20;  - Desktop: `python -m PyInstaller --noconsole --onefile gd\_save\_manager.py`

&#x20;  - Web: `python -m PyInstaller --noconsole --onefile gd\_save\_manager\_web.py`

3\. You will find the `.exe` files in the `dist` folder.

\# GD Save Manager (Десктоп и Веб)



Безопасный и надежный инструмент для локального резервного копирования сохранений \*\*Geometry Dash\*\* и \*\*GDPS\*\*. Позволяет легко сохранить прогресс и восстановить его в случае сбоя.



\## 🚀 Возможности

\- \*\*Две версии:\*\* Классическое приложение для ПК (Tkinter) и современное веб-приложение (работает в браузере).

\- \*\*Кроссплатформенность:\*\* Работает на Windows, macOS и Linux.

\- \*\*Выборочное копирование:\*\* Выбирайте конкретные файлы для сохранения.

\- \*\*Встроенный проводник:\*\* Открывайте папки с сохранениями прямо из программы.

\- \*\*Темы:\*\* Светлая, тёмная, системная и AMOLED (чистый черный).

\- \*\*Локализация:\*\* Поддерживает русский, английский и автоопределение системного языка.

\- \*\*Приватность:\*\* Веб-версия работает полностью локально (`127.0.0.1`) и выключается при закрытии вкладки.



\## 📦 Версии

1\. \*\*Десктоп (`gd\_save\_manager.py`):\*\* Отдельное окно программы. Браузер не нужен.

2\. \*\*Веб (`gd\_save\_manager\_web.py`):\*\* Запускает локальный сервер и открывает красивый интерфейс в браузере.



\## 🛠️ Как запустить (из исходников)

1\. Установите Python (3.8+).

2\. Запустите нужную версию:

&#x20;  - Десктоп: `python gd\_save\_manager.py`

&#x20;  - Веб: `python gd\_save\_manager\_web.py`

3\. \*Сторонние библиотеки не требуются!\*



\## 💻 Как скомпилировать в .exe (Windows)

1\. Установите PyInstaller: `pip install pyinstaller`

2\. Скомпилируйте:

&#x20;  - Десктоп: `python -m PyInstaller --noconsole --onefile gd\_save\_manager.py`

&#x20;  - Веб: `python -m PyInstaller --noconsole --onefile gd\_save\_manager\_web.py`

3\. Готовые `.exe` файлы появятся в папке `dist`.
